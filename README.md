# 速录助手 QuickType

> 把指定文本**直接“敲”到光标所在位置**，专门解决网页 / 软件**禁止复制粘贴**的问题。

`QuickType.exe` 是单文件、免安装的原生 Windows 程序，双击即可用，不依赖 Python / Node / .NET SDK
（只用到 Windows 自带的 .NET Framework 4.x，Win10 / Win11 全都自带）。

---

## 一、三步就能用

1. 双击 `QuickType.exe`（首次运行会在托盘出现一个蓝色圆形“输”图标）。
2. 在左侧编辑框里写下要输入的文字，或者从右侧列表里选一个常用片段。
3. **把光标点进目标输入框**（网页、微信、软件登录框、在线表单……），按 **Ctrl+Alt+Enter**。

文字就会像你亲手打字一样，一个字一个字地敲进去。

> 为什么这样就能绕过“禁止粘贴”？
> 因为程序调用的是 Windows 标准键盘事件接口 `SendInput(KEYEVENTF_UNICODE)`，
> 对目标网页来说等同于你本人在敲键盘——**全程没有任何粘贴动作**，自然不会被拦截，
> 中文、emoji、生僻字、多行文本都能原样输入。

## 二、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+Enter` | 输入左侧编辑框里的当前文本（输入过程中再按一次 = 立即中止） |
| `Ctrl+Alt+1` ~ `Ctrl+Alt+0` | 直接输入对应编号的常用片段，**不用打开本窗口** |
| `Ctrl+Alt+Q` | 显示 / 隐藏主窗口 |

快捷键是**全局生效**的：任何时候、任何软件的输入框里按下去都会起作用。

## 三、界面说明

**左栏 —— 要输入的文本**
- 大文本框：要输入的内容，支持多行、中文、emoji。
- `▶ 输入到光标处`：点它也能输入；勾选了“自动切回上一个窗口”时，程序会先把你上一个
  正在用的窗口切回前台再开始输入，所以点按钮也不会点错地方。
- `读入剪贴板`：把剪贴板里的文字读进编辑框，省得手打。

**左下 —— 输入设置**
- `输入方式`
  - **逐字模拟输入（推荐）**：真实键盘事件，兼容性最好，禁止粘贴的网页也拦不住。
  - **剪贴板粘贴 Ctrl+V**：速度快，但少数网页会拦截粘贴；如果系统剪贴板正被别的程序占用，
    程序会自动降级成逐字输入，保证文字一定送到。
- `开始前等待`：按下到开始输入之间的等待秒数，用来留出“把光标点到目标输入框”的时间；
  用快捷键触发并且光标已经就位时，可以设为 0。
- `字符间隔`：每个字之间的间隔毫秒数。越小越快；**个别输入框吃字（漏字）就把它调大**
  （例如 20~50 毫秒）。
- `关闭窗口时最小化到托盘`：勾上后点右上角 × 只是隐藏窗口，程序仍在后台待命，
  双击托盘图标即可唤回；要真正退出请右键托盘图标 → 退出。

**右栏 —— 常用文本片段**
- `存为新片段`：把左侧文本存成片段，并可指定快捷键（Ctrl+Alt+1~0）。
- `更新选中` / `删除` / `▲` `▼`：修改、删除、调整顺序。
- 双击列表项 = 载入到左侧编辑框；右键列表项 = 直接输入 / 重命名 / 删除。
- 下面下拉框可以随时给选中片段改绑快捷键。若某个组合被其它程序占用，
  窗口底部状态栏会明确提示。

## 四、常见问题

**Q：输入没反应 / 只进了一部分？**
1. 确认光标确实在输入框里（有的网页要先点一下输入框）。
2. 把“开始前等待”调大一点（例如 1 秒），给自己留出点击时间。
3. 把“字符间隔”调大（例如 30 毫秒）——部分编辑器处理按键较慢，间隔太小会漏字。

**Q：快捷键按了没反应？**
多半是被别的程序占用了（输入法、截图工具、显卡驱动等）。看窗口底部状态栏的提示，
换个编号（右侧下拉框里重新绑定）即可。

**Q：怎么让它开机自动运行？**
按 `Win+R` 输入 `shell:startup` 回车，把 `QuickType.exe` 的**快捷方式**拖进去即可。

**Q：配置文件在哪？**
默认就在 `QuickType.exe` 所在目录下的 `config.ini`（UTF-8，可用记事本直接编辑，
改完在菜单“文件 → 重新载入配置”里生效）。
如果 exe 放在没有写入权限的目录（例如 `C:\Program Files`），会自动改用
`%APPDATA%\QuickType\config.ini`。菜单“文件 → 打开配置文件夹”可以直接定位。

**Q：怎么卸载？**
删掉整个文件夹即可；如创建过开机启动项，顺手删掉 `shell:startup` 里的快捷方式。
程序不写注册表、不装服务。

**Q：杀毒软件报毒？**
未签名的自制小工具偶发误报。程序是单文件 exe，源码就在 `src\QuickType.cs`，
可以自己审阅并用 `build.ps1` 一键重新编译。

## 五、目录结构 / 重新编译

```
QuickType\
├─ QuickType.exe          ← 程序本体（单文件，直接双击运行）
├─ 使用说明.md            ← 本文档
├─ build.ps1              ← 一键重新编译（用系统自带 csc.exe）
├─ config.ini             ← 首次运行后自动生成（片段与设置）
├─ src\
│   ├─ QuickType.cs       ← 全部源码（单文件，Win32 P/Invoke + WinForms）
│   └─ app.manifest       ← 程序清单（DPI 感知、现代控件外观）
└─ test\                  ← 自动化测试脚本（可整目录删除）
    ├─ TestHost.cs / TestHost.exe   ← 测试宿主：接收输入并落盘比对
    ├─ run-e2e.ps1                  ← 全局快捷键 + 逐字输入（中文/emoji/多行）
    ├─ run-e2e2.ps1                 ← 片段快捷键 + 剪贴板模式 + 窗口显示隐藏
    └─ ui-check.ps1 / ui-shot.ps1 / ui-dialog.ps1   ← 界面截图与配置保存回路验证
```

重新编译（无需安装任何开发工具）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## 六、已实测通过的项目

| 测试 | 结果 |
| --- | --- |
| 全局快捷键 `Ctrl+Alt+Enter` 把多行文本敲进输入框 | ✅ 98/98 字符完全一致（中文、英文、符号、emoji😀🚀🎉、生僻字龘靐齉） |
| 片段快捷键 `Ctrl+Alt+1` 直接输入片段 | ✅ |
| 剪贴板粘贴模式（含自动降级） | ✅ |
| `Ctrl+Alt+Q` 显示 / 隐藏窗口，隐藏后快捷键仍有效 | ✅ |
| 配置保存 / 重载回路（含多行文本转义） | ✅ |
| 150% 屏幕缩放下界面排版 | ✅ 无错位、无遮挡、无截断 |

> 实现小记：界面一开始用“绝对像素 + Anchor”，在 150% 缩放下控件会被挤出可视区；
> 改用全 `TableLayoutPanel` / `Dock` / `AutoSize` 后发现 WinForms 会在多层嵌套容器里
> 反复套用 `AutoScaleMode.Dpi`，把 `Margin`、`MinimumSize`、`Width` 放大到 16 倍。
> 最终方案是 `AutoScaleMode.None` + 自己按 DPI 换算少量硬尺寸（见源码里的 `S()`），
> 其余全部交给自适应布局，因而在任意缩放下都稳定。
